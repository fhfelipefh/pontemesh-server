# Security Policy

## Supported versions

Security updates are provided for the latest published release.

## Reporting a vulnerability

Do not disclose suspected vulnerabilities in a public issue. Use the repository
Security tab and select **Report a vulnerability** to open a private security
advisory. Include the affected version, reproduction steps, impact, and any
suggested mitigation.

If private vulnerability reporting is unavailable, contact the repository owner
through the GitHub profile before sharing sensitive details.

The architectural threat model and mandatory controls are documented in
[`docs/SECURITY.md`](docs/SECURITY.md).
